# 9. แผนติดตั้งและราคา (สรุป)

ค่าบริการด้านล่างเป็นค่าใช้จ่ายรายเดือนที่ชำระตรงกับผู้ให้บริการภายนอก แยกจากค่าพัฒนาระบบและค่าดูแลระบบรายเดือน (MA)

| รายการ | 9.1 On-Cloud (แนะนำ) | 9.2 On-Premise |
|---|---|---|
| Host & Server | Vercel (แผน Pro) — **20 $/เดือน** | เซิร์ฟเวอร์ของ Fameline — CPU 4 คอร์ · RAM 8 GB · SSD 100 GB · Ubuntu Server LTS (Fameline จัดหา) |
| Database | Supabase (แผน Pro) — **25 $/เดือน** | Supabase แบบติดตั้งเอง (PostgreSQL) — ฟรี ไม่มีค่าลิขสิทธิ์ |
| Domain | ฟรี — โดเมนย่อยของ Vercel หรือโดเมนย่อยของ Fameline | ฟรี — ใช้โดเมนย่อยของ Fameline (จำเป็นต้องมี) |
| SSL (HTTPS) | ฟรี — ออกและต่ออายุอัตโนมัติ | ฟรี — Let's Encrypt ต่ออายุอัตโนมัติ |
| สำรองข้อมูล | อัตโนมัติรายวัน รวมในค่าบริการ | GoAlong ตั้งค่าสำรองอัตโนมัติรายวัน · Fameline จัดหาพื้นที่จัดเก็บ |
| เครือข่าย | อินเทอร์เน็ตทั่วไป | IP สาธารณะแบบคงที่ + เปิดช่องทาง HTTPS ผ่านไฟร์วอลล์ + VPN ให้ GoAlong เข้าดูแล |
| อุปกรณ์เพิ่มเติม | ไม่มี | เครื่องสำรองไฟ (UPS) และพื้นที่สำรองข้อมูลนอกเครื่อง |
| ผู้ดูแลเซิร์ฟเวอร์ | ไม่ต้องมี | ฝ่าย IT ของ Fameline ดูแลเครื่อง ไฟฟ้า และเครือข่าย |
| ระยะเวลาติดตั้ง | 1–2 วันทำการ | ประมาณ 2 สัปดาห์ นับจากวันที่เซิร์ฟเวอร์และเครือข่ายพร้อม |
| **รวมค่าบริการภายนอก/เดือน** | **45 $ (ประมาณ 1,620 บาท)** | **0 $** — มีต้นทุนแฝง: ค่าเครื่อง ค่าไฟ อินเทอร์เน็ต และผู้ดูแลเซิร์ฟเวอร์ |

**หมายเหตุ**
- ราคาอ้างอิงแผนมาตรฐานของผู้ให้บริการ ณ วันที่จัดทำเอกสาร คิดที่ประมาณ 36 บาทต่อดอลลาร์สหรัฐ ยังไม่รวมภาษี และอาจมีค่าใช้จ่ายเพิ่มหากปริมาณใช้งานเกินโควตาของแผน
- Vercel คิดค่าบริการต่อ 1 บัญชีผู้ดูแล
- แผนฟรีของทั้งสองผู้ให้บริการไม่เหมาะกับงานจริง เนื่องจากไม่อนุญาตการใช้งานเชิงพาณิชย์ และไม่มีการสำรองข้อมูลอัตโนมัติ
- On-Premise ยังต้องเข้าถึงได้จากอินเทอร์เน็ต เพราะลิงก์จองคิว หน้าคนขับ และการแจ้งเตือน LINE ถูกเรียกจากภายนอกองค์กร
