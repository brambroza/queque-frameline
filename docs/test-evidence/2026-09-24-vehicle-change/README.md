## ขั้นตอนสำหรับลูกค้า (ทำเองจากลิงก์ที่คลังส่งให้ ไม่ต้องโทร)

1. เปิด **ลิงก์จองคิวของ SO** (ลิงก์/QR เดิมที่ใช้จอง — เปิดใน LINE หรือเบราว์เซอร์ก็ได้)
2. ในการ์ดคิวที่ต้องการ กดปุ่ม **"เปลี่ยนทะเบียนรถ / คนขับ"** (มีเฉพาะคิวที่รถยังไม่มาถึง: รอยืนยัน / ยืนยันแล้ว / เลยเวลานัด)
3. ฟอร์มเปิดขึ้นในการ์ด กรอกค่าใหม่:
   - **ทะเบียนรถ** (บังคับ, ต้องตรงรูปแบบของประเภทรถ — รถบรรทุก = เลขหมวด 2 หลัก-เลข 4 หลัก เช่น `70-1234`; ระบบช่วยใส่ขีดให้)
   - **ชื่อคนขับ**, **เบอร์คนขับ** (ไม่บังคับ)
   - ⚠ เปลี่ยน**ประเภทรถ** (เช่น 6 ล้อ → 10 ล้อ) ไม่ได้ในฟอร์มนี้ เพราะกระทบเวลาที่ท่า — ต้องยกเลิกคิวแล้วจองใหม่ หรือติดต่อคลัง
4. กด **"บันทึกและแจ้งคลัง"** → ขึ้นแถบเขียว "บันทึกแล้ว — แจ้งคลังเรื่องรถ/คนขับของคิว R-008 แล้ว" การ์ดแสดงทะเบียน/คนขับใหม่ทันที
5. ไม่ต้องขอ DO ใหม่ — เลข DO / เลขคิว / ท่า / เวลา คงเดิม ลิงก์คนขับเดิมใช้ต่อได้ (คนขับคนใหม่เปิดลิงก์เดิมจะเห็นชื่อตัวเอง)
6. ป้อมยามจะตรวจทะเบียนตามข้อมูลใหม่ — ถ้ารถมาถึงคลังแล้ว (เช็คอิน/ถูกเรียก) จะแก้ไม่ได้ ต้องแจ้งเจ้าหน้าที่หน้าประตูให้แก้ทะเบียนที่ประตูแทน
