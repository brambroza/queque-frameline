ภาพรวม

บทบาทและสิทธิ์การใช้งาน

ผู้ดูแลระบบใช้งานได้ทุกเมนู และเป็นผู้กำหนดสิทธิ์ของผู้ใช้งานทั้งหมด

เมนูเฉพาะผู้ดูแลระบบ

  • พนักงาน และ สิทธิ์และเมนู
  • สาขา
  • ตั้งค่า (ข้อมูลคลัง)
  • ตั้งค่า LINE
  • เชื่อมต่อ ERP
  • จัดการภาษา
  • ประวัติการใช้งาน

เมนูที่ใช้ร่วมกับคลัง

  • งานประจำวัน: แดชบอร์ด คิว SO / PO ปฏิทิน บอร์ดคิว จอคิว
  • ตั้งค่าคลัง: ประเภทรถ ท่า เวลาทำการ วันหยุด คู่ค้า ตั้งค่าระบบคิว
  • รายงาน
หมายเหตุ · ขั้นตอนงานประจำวันและการตั้งค่าคลัง ดูรายละเอียดใน คู่มือผู้จัดการคลัง ส่วนการบันทึก SO / PO ดูใน คู่มือแอดมินฝ่ายขาย และ คู่มือฝ่ายจัดซื้อ
Go Along Co., Ltd.03

เริ่มต้นใช้งาน

เข้าสู่ระบบ

ผู้ใช้งานภายในเข้าระบบด้วยอีเมลและรหัสผ่านของตนเอง

  1. เปิดเว็บไซต์ของระบบด้วยเบราว์เซอร์ (แนะนำ Google Chrome หรือ Microsoft Edge)
  2. กรอก อีเมล และ รหัสผ่าน
  3. กด เข้าสู่ระบบ ระบบจะเปิดเมนูแรกที่ท่านมีสิทธิ์ใช้งาน
หมายเหตุ · ผู้ใช้ใหม่จะได้รับอีเมลเชิญจากผู้ดูแลระบบ กดลิงก์ในอีเมลเพื่อตั้งรหัสผ่านครั้งแรก ระบบไม่มีหน้าสมัครสมาชิกเอง
ลืมรหัสผ่าน · กด ลืมรหัสผ่าน? ที่หน้าเข้าสู่ระบบ หรือแจ้งผู้ดูแลระบบ

พนักงาน

เพิ่มและจัดการพนักงาน

ผู้ใช้งานภายในทุกคนต้องถูกเพิ่มจากหน้านี้ พนักงาน 1 คนมี 1 สิทธิ์

  1. เมนู พนักงาน กด เพิ่มพนักงาน
  2. กรอกชื่อ อีเมล และเลือก สิทธิ์ ระบบส่งอีเมลเชิญให้ผู้ใช้ตั้งรหัสผ่านเอง
  3. เปลี่ยนสิทธิ์ ปิดการใช้งาน หรือลบ ได้จากปุ่มท้ายแถว
ข้อควรระวัง · ผู้ดูแลระบบเปลี่ยนสิทธิ์หรือลบบัญชีของตนเองไม่ได้ และระบบต้องมีผู้ดูแลระบบอย่างน้อย 1 คน

พนักงาน

สิทธิ์และเมนู

สิทธิ์ (Role) กำหนดระดับการใช้งาน เมนูที่เห็น และสาขาที่เข้าถึง

สิทธิ์มาตรฐานระดับขอบเขตงาน
ผู้ดูแลระบบผู้ดูแลระบบทุกเมนู รวมการจัดการพนักงาน สิทธิ์ สาขา LINE และ ERP
ผู้จัดการคลังผู้จัดการงานหน้างานทั้งหมด รายงาน และตั้งค่าคลัง
แอดมินคลังพนักงานคิว บอร์ดคิว ปฏิทิน SO / PO จอคิว
แอดมินฝ่ายขายพนักงานบันทึก SO และส่งลิงก์จอง
ฝ่ายจัดซื้อพนักงานบันทึก PO และส่งลิงก์จอง
ผู้บริหารดูอย่างเดียวแดชบอร์ด ปฏิทิน บอร์ดคิว รายงาน
หมายเหตุ · สิทธิ์มาตรฐานลบหรือเปลี่ยนระดับไม่ได้ แต่ปรับเมนูและสาขาได้ ผู้ดูแลระบบสร้างสิทธิ์เพิ่มได้ตามต้องการ

เพิ่มหรือแก้ไขสิทธิ์

กำหนดระดับสิทธิ์ เมนู สาขา และสิทธิ์ส่งออกข้อมูลของแต่ละสิทธิ์

  1. แท็บ สิทธิ์และเมนู กด เพิ่มสิทธิ์ หรือ แก้ไข ที่สิทธิ์ที่ต้องการ
  2. เลือก ระดับสิทธิ์: ผู้ดูแลระบบ · ผู้จัดการ · พนักงาน · ดูอย่างเดียว
  3. เลือกเมนูที่เห็น หรือเปิด เห็นทุกเมนูที่ระดับนี้อนุญาต
  4. ส่วน สาขาและข้อมูล: จำกัดสาขา เปิด–ปิดการส่งออกข้อมูล และการดูหลายสาขาพร้อมกัน
  5. กด บันทึก มีผลเมื่อผู้ใช้เปิดหน้าใหม่

จัดการคลัง

สาขา / คลัง

ท่า เวลาทำการ วันหยุด และเอกสาร ผูกกับสาขา

  1. เมนู สาขา กด เพิ่มสาขา หรือรูปดินสอเพื่อแก้ไข
  2. กรอกรหัสสาขา ชื่อ ที่อยู่ และเบอร์โทร
  3. กำหนด พิกัดคลัง โดยวางพิกัดจาก Google Maps หรือกดใช้ตำแหน่งปัจจุบัน และระบุรัศมีเช็คอิน (เมตร)
หมายเหตุ · รหัสสาขา ต้องตรงกับรหัสคลังในระบบ ERP เพื่อให้เอกสารเข้าสาขาถูกต้อง
พิกัด · สาขาที่กำหนดพิกัด คนขับต้องอยู่ในรัศมีจึงเช็คอินเองได้ สาขาที่ไม่กำหนด ระบบไม่ตรวจตำแหน่ง

รายงาน & ตั้งค่า

ข้อมูลคลังและตั้งค่าระบบคิว

ข้อมูลที่แสดงต่อคู่ค้า และกติกาของคิวทั้งระบบ

ซ้าย: ตั้งค่า (ข้อมูลคลัง) · ขวา: ตั้งค่าระบบคิว

  1. เมนู ตั้งค่า: แก้ชื่อคลัง เบอร์โทร ที่อยู่ และโลโก้ แล้วกด บันทึกโปรไฟล์ ข้อมูลนี้แสดงบนหน้าจองของคู่ค้า ใบ DO และจอเรียกคิว
  2. เมนู ตั้งค่าระบบคิว: เวลาเผื่อ การเรียกคิวอัตโนมัติ เวลาตามรายการสินค้า กติกาการจอง คิวที่ยังไม่ชำระเงิน และรูปแบบเลข DO
หมายเหตุ · รายละเอียดแต่ละหัวข้อของตั้งค่าระบบคิว ดูในคู่มือผู้จัดการคลัง

รายงาน & ตั้งค่า

ตั้งค่า LINE

เชื่อม LINE Official Account เพื่อแจ้งเตือนคู่ค้า คนขับ และกลุ่มทีมคลัง

  1. กรอก Channel access token และ Channel secret ของ Messaging API แล้วนำ Webhook URL ไปตั้งใน LINE Developers
  2. กรอก LIFF ID และ Login channel ID เพื่อให้คู่ค้าผูกบัญชีเมื่อเปิดลิงก์ผ่าน LINE
  3. เชิญ OA เข้ากลุ่มทีมคลัง แล้วพิมพ์ ลงทะเบียนกลุ่ม ในกลุ่มนั้น
  4. กด เผยแพร่ เมนูลูกค้า (คิวของฉัน · สถานะ SO · ติดต่อคลัง) และเลือกเปิด–ปิดการแจ้งเตือนแต่ละประเภท
  5. กดทดสอบการเชื่อมต่อเพื่อยืนยัน
ข้อควรระวัง · Token และ Secret เป็นข้อมูลลับ ห้ามส่งต่อทางแชตหรืออีเมล

รายงาน & ตั้งค่า

เชื่อมต่อ ERP

ออก API key ให้ระบบ ERP ส่ง SO / PO เข้ามาอัตโนมัติ และตรวจประวัติการรับข้อมูล

  1. เมนู เชื่อมต่อ ERP กด สร้าง API key ตั้งชื่อให้สื่อถึงระบบที่ใช้
  2. คัดลอก key ที่แสดง แล้วส่งให้ผู้ดูแลระบบ ERP ผ่านช่องทางที่ปลอดภัย
  3. ตรวจ ประวัติการรับข้อมูล ด้านล่าง: จำนวนเอกสารที่สร้าง อัปเดต และไม่สำเร็จ
ข้อควรระวัง · key แสดงเพียงครั้งเดียวตอนสร้าง หากสูญหายให้เพิกถอนแล้วสร้างใหม่ การเพิกถอนยกเลิกไม่ได้

รายงาน & ตั้งค่า

จัดการภาษาและประวัติการใช้งาน

ปรับข้อความบนหน้าจอ และตรวจสอบการแก้ไขข้อมูลย้อนหลัง

  1. เมนู จัดการภาษา: ค้นหาข้อความ แก้คำแปลภาษาไทยหรืออังกฤษ แล้วบันทึก
  2. เมนู ประวัติการใช้งาน: แสดงการเพิ่ม แก้ไข และลบข้อมูลจากทุกหน้า กรองตามการกระทำ ประเภทข้อมูล ผู้ใช้ และช่วงวัน
หมายเหตุ · ประวัติการใช้งานเป็นข้อมูลอ่านอย่างเดียว ส่วนประวัติของคิวแต่ละรายการดูได้จากแท็บไทม์ไลน์ของคิวนั้น

แนวปฏิบัติ

รายการตรวจสอบก่อนเปิดใช้งาน

ลำดับการตั้งค่าที่แนะนำสำหรับคลังใหม่

  1. ข้อมูลคลัง — ชื่อ ที่อยู่ เบอร์โทร โลโก้
  2. สาขา — รหัสสาขา พิกัด และรัศมีเช็คอิน
  3. ประเภทรถ และ ท่ารับ-ส่งสินค้า — เวลาที่ท่า และประเภทงานของแต่ละท่า
  4. เวลาทำการ และ วันหยุด
  5. ตั้งค่าระบบคิว — เวลาเผื่อ การเรียกคิวอัตโนมัติ กติกาการจอง
  6. สิทธิ์และเมนู — ตรวจเมนูและสาขาของแต่ละสิทธิ์
  7. พนักงาน — เชิญผู้ใช้และกำหนดสิทธิ์
  8. ตั้งค่า LINE และ เชื่อมต่อ ERP (ถ้าใช้งาน)
  9. ทดสอบ 1 รอบ: บันทึก SO → ส่งลิงก์ → จองคิว → อนุมัติ → เช็คอิน → เรียก → ปิดงาน

ความปลอดภัย

  • ใช้บัญชีของตนเอง ไม่ใช้บัญชีร่วมกัน
  • ปิดการใช้งานบัญชีของผู้ที่พ้นหน้าที่ทันที
  • กำหนดสิทธิ์เท่าที่จำเป็นต่องาน

เมื่อพบปัญหา

  • กดปุ่มแจ้งปัญหามุมซ้ายล่างของทุกหน้า
  • ระบุขั้นตอนที่ทำและผลที่เกิดขึ้น
  • ระบบแนบภาพหน้าจอให้อัตโนมัติ
