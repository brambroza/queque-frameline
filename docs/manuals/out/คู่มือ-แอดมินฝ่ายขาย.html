ภาพรวม

บทบาทและสิทธิ์การใช้งาน

แอดมินฝ่ายขาย รับผิดชอบเอกสาร ใบสั่งขาย (SO) และการส่งลิงก์จองคิวให้ลูกค้า

เมนูที่ใช้งานได้

  • ใบสั่งขาย (SO) — บันทึกเอกสาร ส่งลิงก์จอง ติดตามสถานะคิว
  • การแจ้งเตือน — เหตุการณ์ของคิวและเอกสาร

สิ่งที่ทำได้

  • เพิ่ม แก้ไข ปิด ยกเลิก และลบ SO
  • ออกและส่งลิงก์จองคิว / QR ให้ลูกค้า
  • บันทึกสถานะการชำระเงินของ SO
  • สร้างคิว Walk-in ให้รถที่มาถึงโดยไม่ได้จอง

ขั้นตอนงานโดยสรุป

  1. บันทึกใบสั่งขาย (SO) เข้าระบบ
  2. บันทึกสถานะการชำระเงิน
  3. ส่งลิงก์จองคิว / QR ให้ลูกค้า
  4. ลูกค้าจองคิวด้วยตนเอง เจ้าหน้าที่คลังอนุมัติและออกใบ DO
  5. ติดตามสถานะคิวจนปิดงาน
หมายเหตุ · การอนุมัติคิว ออกใบ DO เรียกรถ และปิดงาน เป็นหน้าที่ของเจ้าหน้าที่คลัง แอดมินฝ่ายขายติดตามสถานะได้จากหน้าใบสั่งขาย (SO)

ใบสั่งขาย (SO)

เพิ่มใบสั่งขาย (SO)

บันทึก SO ทีละใบก่อนส่งลิงก์จองคิว

  1. กด เพิ่ม SO มุมขวาบน
  2. เลือก สาขา / คลัง ที่ลูกค้ามารับสินค้า แล้วกรอก เลขที่ SO วันที่เอกสาร และกำหนดส่ง
  3. เลือก สถานะการชำระเงิน (ยังไม่ชำระ / ชำระแล้ว / เครดิต)
  4. พิมพ์ชื่อลูกค้า แล้วเลือกจากรายการ ระบบเติมรหัสและเบอร์โทรให้ หากเป็นรายใหม่ให้กรอกชื่อและเบอร์โทร ระบบบันทึกเป็นคู่ค้าใหม่อัตโนมัติ
  5. กด บันทึกเอกสาร
หมายเหตุ · เลขที่เอกสารซ้ำกับที่มีอยู่ ระบบจะอัปเดตเอกสารเดิม ไม่สร้างใบใหม่
สาขา · ลูกค้าจะเห็นเฉพาะท่าและเวลาทำการของสาขาที่เลือก และเปลี่ยนสาขาไม่ได้ขณะมีคิวที่ยังไม่ปิด

ใบสั่งขาย (SO)

บันทึกการชำระเงิน

SO ต้องมีสถานะ ชำระแล้ว หรือ เครดิต เจ้าหน้าที่คลังจึงจะอนุมัติคิวได้

  1. ที่แถวของ SO ซึ่งยังไม่ชำระ กด บันทึกชำระเงิน
  2. เลือกสถานะ ชำระแล้ว หรือ เครดิต
  3. ระบุเลขอ้างอิงและหมายเหตุ (ไม่บังคับ)
  4. กด บันทึก ระบบแจ้งเจ้าหน้าที่คลังว่าคิวของ SO ใบนี้อนุมัติได้แล้ว
หมายเหตุ · SO ที่ยังไม่ชำระ ลูกค้ายังจองคิวได้ แต่คิวจะอยู่ที่สถานะ รอยืนยัน จนกว่าจะบันทึกการชำระเงิน
ข้อควรระวัง · เปลี่ยนกลับเป็น ยังไม่ชำระ ได้เฉพาะเมื่อยังไม่มีคิวที่อนุมัติแล้ว
ยกเลิกอัตโนมัติ · หากเปิดใช้การยกเลิกคิวที่ยังไม่ชำระเงินอัตโนมัติ คิวที่ลูกค้าจองเองจะถูกยกเลิกเมื่อครบเวลาที่กำหนด โดยระบบเตือนลูกค้าก่อน 1 ครั้ง

ใบสั่งขาย (SO)

ส่งลิงก์จองคิว / QR

ลิงก์และ QR เป็นของเอกสารใบนั้นโดยเฉพาะ ลูกค้าใช้จองคิวด้วยตนเอง

  1. ที่แถวของเอกสาร กด ส่งลิงก์จอง (หรือ ดูลิงก์ หากเคยออกลิงก์แล้ว)
  2. กด คัดลอกลิงก์ แล้วส่งให้ลูกค้าทาง LINE อีเมล หรือช่องทางอื่น หรือให้สแกน QR
  3. กรณีลูกค้าผูกบัญชี LINE กับระบบแล้ว จะมีปุ่มส่งลิงก์ทาง LINE ให้โดยตรง
หมายเหตุ · ลิงก์มีวันหมดอายุตามที่แสดงใต้ช่องลิงก์ เอกสารที่ปิดหรือยกเลิกแล้วจะจองไม่ได้
ข้อควรระวัง · สร้างลิงก์ใหม่ ทำให้ลิงก์เดิมใช้ไม่ได้ทันที ใช้เมื่อลิงก์หมดอายุหรือส่งผิดผู้รับเท่านั้น

ติดตามสถานะคิวของเอกสาร

ตรวจสอบว่าเอกสารมีคิวแล้วหรือไม่ และคิวอยู่ที่ขั้นตอนใด

  1. กด เลขที่เอกสาร ในรายการ
  2. ส่วน คิว แสดงเลขคิว วันเวลา ท่า ทะเบียนรถ เลข DO และสถานะของทุกเที่ยว
  3. กด แก้ไข เพื่อแก้ข้อมูลเอกสาร หรือ ดูลิงก์จอง เพื่อส่งลิงก์ซ้ำ
สถานะคิวความหมาย
รอยืนยันมีคำขอจองแล้ว รอเจ้าหน้าที่คลังอนุมัติ (SO ที่ยังไม่ชำระเงินจะค้างที่สถานะนี้)
ยืนยันแล้วอนุมัติแล้ว ระบบออกเลขใบ DO และลิงก์สำหรับคนขับ
เลยเวลานัดเลยเวลานัดเกินเวลาเผื่อ รถยังเช็คอินได้เมื่อมาถึง
มาถึงแล้ว · รอเรียกรถเช็คอินแล้ว รอในลานจนกว่าท่าจะว่าง
กำลังเรียกเข้าท่าระบบหรือเจ้าหน้าที่เรียกรถเข้าท่าแล้ว
กำลังขึ้น/ลงของรถอยู่ที่ท่า กำลังขึ้นหรือลงสินค้า
เสร็จสิ้นปิดงานแล้ว
ไม่มา / ยกเลิกรถไม่มาตามนัด หรือคิวถูกยกเลิก ช่วงเวลานั้นกลับมาว่าง

ใบสั่งขาย (SO)

Walk-in — รถมาถึงโดยไม่ได้จอง

สร้างคิวของวันนี้ให้รถที่มาถึงคลังแล้ว ระบบเช็คอินให้อัตโนมัติ

  1. ที่แถวของเอกสาร กด รูปรถ (Walk-in)
  2. เลือก ประเภทรถ กรอกทะเบียนรถ ชื่อและเบอร์โทรคนขับ
  3. ดูการ์ดสรุปด้านบน แล้วแตะช่องเวลา ว่าง (สีเขียว) หากเวลาทำการเต็มแล้ว เลือกช่อง ต่อท้าย (สีส้ม)
  4. กด สร้างคิว + เช็คอิน หรือ ต่อท้ายคิว + เช็คอิน ระบบแสดงเลขคิว เลข DO ท่า และ QR ลิงก์สำหรับคนขับ
หมายเหตุ · Walk-in ต้องผูกกับ SO เสมอ และใช้ได้เฉพาะวันนี้ ช่อง เต็ม (สีเทา) เลือกไม่ได้
ข้อควรระวัง · SO ที่ยังไม่ชำระเงิน คิวจะเป็น รอยืนยัน ยังไม่ออก DO และยังไม่เช็คอิน จนกว่าจะบันทึกการชำระเงินและอนุมัติ

แก้ไข ปิด ยกเลิก และลบเอกสาร

ปุ่มจัดการอยู่ท้ายแถวของเอกสารแต่ละใบ

ปุ่มผลลัพธ์เงื่อนไข
แก้ไข (รูปดินสอ)แก้ข้อมูลเอกสาร เช่น กำหนดส่ง ลูกค้า หมายเหตุเลขที่เอกสารแก้ไม่ได้
ปิดปิดเอกสารเมื่อส่งมอบครบแล้ว จองคิวเพิ่มไม่ได้สถานะเป็น ปิดแล้ว
ยกเลิกยกเลิกเอกสาร ลิงก์จองใช้ไม่ได้ต้องยกเลิกคิวที่ยังไม่ปิดก่อน
เปิดใหม่นำเอกสารที่ปิดหรือยกเลิกกลับมาใช้—
ลบ (รูปถังขยะ)ลบเอกสารออกจากรายการเฉพาะเอกสารที่ยังไม่มีคิว
หมายเหตุ · เอกสารที่ส่งมาจากระบบ ERP หากแก้ไขที่หน้านี้ ค่าจะถูกทับเมื่อ ERP ส่งเอกสารเลขเดิมมาอีกครั้ง

ข้อแนะนำ

ก่อนส่งลิงก์

  • ตรวจสาขาและกำหนดส่งให้ถูกต้อง
  • บันทึกการชำระเงินให้เป็นปัจจุบัน

เมื่อมีการเปลี่ยนแปลง

  • ลูกค้าเปลี่ยนทะเบียนรถหรือคนขับได้เองจากลิงก์ ก่อนรถเช็คอิน
  • การเลื่อนวันหรือเวลา ให้ประสานเจ้าหน้าที่คลัง

ทั่วไป

การแจ้งเตือนและการแจ้งปัญหา

ติดตามเหตุการณ์ของคิว และแจ้งปัญหาการใช้งานถึงผู้พัฒนาได้จากทุกหน้า

ซ้าย: หน้าการแจ้งเตือน · ขวา: แบบฟอร์มแจ้งปัญหา / แนะนำการใช้งาน

  1. กดรูป กระดิ่ง มุมขวาบน หรือเมนู การแจ้งเตือน เพื่อดูรายการล่าสุด ตัวเลขสีแดงคือรายการที่ยังไม่ได้อ่าน
  2. กด Mark read เมื่ออ่านแล้ว หรือ Archive เพื่อเก็บรายการ
  3. พบปัญหาการใช้งาน กด ปุ่มวงกลมสีเขียวมุมซ้ายล่าง ระบบจะแนบภาพหน้าจอปัจจุบันให้อัตโนมัติ
  4. เลือกประเภท (แจ้งปัญหา / แนะนำการปรับปรุง) ระบุลำดับความสำคัญและรายละเอียด แล้วกด ส่งรายงาน

ภาคผนวก

ขั้นตอนที่ลูกค้าเห็นเมื่อเปิดลิงก์

ใช้อธิบายลูกค้าเมื่อสอบถามวิธีจองคิว

  4. หลังจองแล้ว หน้าเดิมแสดงสถานะคิว และมีปุ่ม เปลี่ยนทะเบียนรถ / คนขับ กับ ยกเลิกคิวนี้
