รายการคิว

คิวทั้งหมดของวันที่เลือก พร้อมปุ่มดำเนินการขั้นถัดไปของแต่ละคิว

  1. เลือกช่วง วันนี้ · พรุ่งนี้ · ทั้งหมด · เลือกวัน และกรองตามสถานะ ประเภทงาน หรือท่า
  2. ค้นหาจากเลขคิว ทะเบียนรถ หรือเลข DO
  3. ปุ่มสีเขียวท้ายแถวคือขั้นตอนถัดไปของคิวนั้น
  4. กด รายละเอียด เพื่อเปิดข้อมูลคิว ไทม์ไลน์ ใบ DO และลิงก์คนขับ
  5. กด สร้างคิว เพื่อจองคิวแทนคู่ค้า หรือ Walk-in สำหรับรถที่มาถึงโดยไม่ได้จอง

คิวรับ-ส่งสินค้า

อนุมัติคิวและออกใบ DO

คำขอจองจากลิงก์จะอยู่ที่สถานะ รอยืนยัน จนกว่าเจ้าหน้าที่คลังอนุมัติ

  1. ที่คิวสถานะ รอยืนยัน กด อนุมัติคิว + ออก DO
  2. ตรวจ เวลาที่ท่า (นาที) ระบบแนะนำจากประเภทรถ หรือจำนวนรายการสินค้าของเอกสาร
  3. ดูแถบเวลาของท่าในวันนั้น ปรับนาทีได้โดยไม่ให้ชนคิวถัดไป
  4. กดยืนยัน ระบบออกเลข DO และส่งใบ DO พร้อมลิงก์คนขับให้คู่ค้าทาง LINE (หากผูกไว้)
ข้อควรระวัง · SO ที่ยังไม่ชำระเงินอนุมัติไม่ได้ ต้องบันทึกเป็น ชำระแล้ว หรือ เครดิต ก่อน ส่วน PO อนุมัติได้ทันที
หมายเหตุ · เลข DO ออกอัตโนมัติ ไม่ซ้ำ และเรียงต่อเนื่องภายในเดือน

รายละเอียดคิวและไทม์ไลน์

ข้อมูลของคิว ขั้นตอนถัดไป และประวัติการเปลี่ยนสถานะ

ซ้าย: แท็บข้อมูล · ขวา: แท็บไทม์ไลน์

  1. แท็บ ข้อมูล แสดงวันเวลา ท่า ประเภทรถ เอกสาร การชำระเงิน เลข DO รถและคนขับ
  2. ส่วน ขั้นตอนถัดไป มีปุ่มตามสถานะ เช่น เริ่มขึ้น/ลงของ เรียกซ้ำ ยกเลิกการเรียก ไม่มา
  3. แท็บ ไทม์ไลน์ บันทึกว่าใครทำอะไร เมื่อไร ใช้ตรวจสอบย้อนหลัง
  4. ยกเลิกคิว ต้องระบุเหตุผล คู่ค้าจะเห็นเหตุผลนั้นในหน้าลิงก์ของตน

คิวรับ-ส่งสินค้า

ใบ DO ลิงก์คนขับ และการแก้ทะเบียนรถ

พิมพ์ใบ DO ส่งลิงก์ให้คนขับ และบันทึกทะเบียนรถที่มาจริง

ซ้าย: แท็บ DO · ขวา: แท็บลิงก์คนขับ

  1. แท็บ DO กด พิมพ์ / บันทึกเป็น PDF เพื่อพิมพ์ใบรับ–ส่งสินค้า
  2. แท็บ ลิงก์คนขับ ให้คนขับสแกน QR หรือกด คัดลอกลิงก์ ส่งต่อ คนขับใช้ดู DO ท่า และเช็คอินโดยไม่ต้องเข้าสู่ระบบ
  3. ทะเบียนรถที่มาจริงไม่ตรงกับที่จอง กด แก้ทะเบียน ในแท็บข้อมูล กรอกทะเบียนจริงและเหตุผล
หมายเหตุ · ระบบเก็บทั้งทะเบียนที่จองและทะเบียนที่มาจริง พร้อมชื่อผู้แก้ไข

คิวรับ-ส่งสินค้า

จัดตารางคิว — เลื่อนวัน เวลา ท่า

ย้ายคิวหรือปรับเวลาที่ท่าในหน้าต่างเดียว ระบบตรวจไม่ให้ซ้อนกับคิวอื่นบนท่าเดียวกัน

ซ้าย: มุมมองเลือกช่องเวลา · ขวา: มุมมองบอร์ด (ลาก)

  1. เปิดรายละเอียดคิว กด จัดตารางคิว — วัน / เวลา
  2. เลือกวันจากแถบด้านบน
  3. มุมมอง เลือกช่องเวลา: แตะช่องที่ว่างของท่าที่ต้องการ · มุมมอง บอร์ด (ลาก): ลากบล็อกของคิวไปยังท่าหรือเวลาใหม่ และลากขอบล่างเพื่อปรับเวลาที่ท่า
  4. ตรวจสรุปการเปลี่ยนแปลง แล้วกดบันทึก
หมายเหตุ · ย้ายข้ามวัน ระบบออกเลขคิวใหม่ของวันปลายทาง เลข DO และลิงก์คนขับคงเดิม

ปิดงานและลงชื่อ

Walk-in — รถมาถึงโดยไม่ได้จอง

สร้างคิวของวันนี้และเช็คอินในขั้นตอนเดียว

  1. กด Walk-in บนบอร์ดคิว หรือหน้าคิวรับ-ส่งสินค้า
  2. เลือกประเภทงาน แล้วเลือก เอกสาร SO / PO ของรถคันนั้น
  3. เลือกประเภทรถ กรอกทะเบียนรถและข้อมูลคนขับ
  4. การ์ดสรุปบอกเวลาปัจจุบัน จำนวนช่องที่ว่าง และช่องที่เร็วที่สุด แตะช่อง ว่าง (สีเขียว)
  5. กด สร้างคิว + เช็คอิน หากท่าว่าง ระบบเรียกเข้าท่าให้ทันที
ป้ายบนช่องเวลาความหมาย
