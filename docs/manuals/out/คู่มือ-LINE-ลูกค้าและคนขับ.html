ภาพรวม

LINE OA ช่วยอะไรบ้าง

LINE OA ของคลังส่งแจ้งเตือนสถานะคิวให้อัตโนมัติ และเปิดดูคิวของท่านได้ตลอดเวลา

ลูกค้า / ผู้ขาย

  • รับลิงก์จองคิวของ SO / PO
  • แจ้งเมื่อรับคำขอจอง ยืนยันคิว เลื่อน หรือยกเลิก
  • ได้เลข DO และลิงก์สำหรับคนขับ
  • เมนู: คิวของฉัน · สถานะ SO · ติดต่อคลัง

คนขับ

  • รับใบงาน: เลขคิว วันเวลา ท่า เลข DO
  • แจ้งเมื่อถึงคิว พร้อมชื่อท่าที่ต้องเข้า
  • แจ้งเมื่อท่ายังไม่ว่าง หรือเลยเวลานัด
  1. เพิ่มเพื่อน LINE OA ของคลัง (@307ghkbr)
  2. เปิดลิงก์จองคิวที่ได้รับจากฝ่ายขาย / ฝ่ายจัดซื้อ ผ่าน LINE 1 ครั้ง ระบบจะจำบัญชี LINE ของท่าน
  3. จองคิว แล้วรอรับแจ้งเตือนทาง LINE
  4. ส่งต่อลิงก์สำหรับคนขับให้ผู้ขับรถ คนขับเปิดผ่าน LINE เพื่อรับแจ้งเมื่อถึงคิว
หมายเหตุ · LINE OA ตอบกลับอัตโนมัติเท่านั้น ไม่มีเจ้าหน้าที่อ่านแชท หากต้องการสอบถาม กรุณาติดต่อเจ้าหน้าที่โดยตรง

เริ่มต้นใช้งาน

เปิดลิงก์จองคิวผ่าน LINE

การเปิดลิงก์ผ่าน LINE ครั้งแรกคือการผูกบัญชี LINE ของท่านกับเอกสาร

ซ้าย: ลิงก์จองที่ส่งทาง LINE · กลาง: หน้าจองคิว · ขวา: จองสำเร็จ

  1. ฝ่ายขาย / ฝ่ายจัดซื้อส่งลิงก์จองคิวของเอกสารให้ทาง LINE OA (การ์ด จองคิวรับสินค้า) หรือส่งลิงก์ / QR ทางช่องทางอื่น
  2. กด เลือกวันและเวลา หน้าจองคิวจะเปิดภายใน LINE และแสดง ✅ รับแจ้งเตือนทาง LINE แล้ว
  3. เลือกประเภทรถ วัน และช่วงเวลา กรอกทะเบียนรถ ชื่อคนขับ และเบอร์โทรคนขับ (จำเป็นทั้ง 3 ช่อง) แล้วยืนยัน
ข้อควรระวัง · หากเปิดลิงก์ในเบราว์เซอร์ (Chrome / Safari) ระบบยังจองได้ แต่จะไม่รู้จักบัญชี LINE ให้กดแถบ เปิดใน LINE ด้านบนหน้าจอ
หมายเหตุ · ลิงก์จองใช้ได้กับเอกสารฉบับนั้นเท่านั้น และมีวันหมดอายุ หากลิงก์หมดอายุ ขอลิงก์ใหม่จากเจ้าหน้าที่

แจ้งเตือน

ข้อความที่ได้รับหลังจองคิว

ระบบส่งการ์ดสถานะทุกครั้งที่คิวเปลี่ยน ทุกการ์ดมีปุ่มเปิดดูรายละเอียด

ซ้าย: รับคำขอจองแล้ว · กลาง: ยืนยันคิว + เลข DO · ขวา: เลยเวลานัด

  1. รับคำขอจองคิวแล้ว — รอเจ้าหน้าที่ยืนยัน หรือรอชำระเงิน (SO ที่ยังไม่ชำระ)
  2. ยืนยันคิวแล้ว — ได้เลข DO กด ลิงก์สำหรับคนขับ เพื่อส่งต่อให้ผู้ขับรถ
  3. มาถึงคลังตามเวลานัด แจ้งเลขคิวที่ป้อมยาม

แจ้งเตือน

รายการแจ้งเตือนทั้งหมด

ข้อความที่ลูกค้า / ผู้ขาย และคนขับอาจได้รับ และสิ่งที่ควรทำ

ข้อความได้รับเมื่อผู้รับสิ่งที่ควรทำ
รับคำขอจองคิวแล้วจองคิวผ่านลิงก์สำเร็จลูกค้า / ผู้ขายรอเจ้าหน้าที่ยืนยัน หรือชำระเงิน (SO)
คิวกำลังจะถูกยกเลิกSO ยังไม่ชำระเงิน ใกล้ถึงกำหนดลูกค้าชำระเงินและแจ้งฝ่ายขายก่อนเวลาที่ระบุ
ยืนยันคิวแล้วเจ้าหน้าที่อนุมัติ ออกเลข DOลูกค้า / ผู้ขายส่งต่อลิงก์คนขับ มาตามนัด
งานรับ / ส่งสินค้า (ใบงาน)เจ้าหน้าที่ส่งใบงานทาง LINEคนขับเปิดลิงก์ดู DO และท่า
เจ้าหน้าที่เลื่อนคิวคลังเปลี่ยนวัน เวลา หรือท่าลูกค้า / ผู้ขายตรวจเวลาใหม่ แจ้งคนขับ
คิวล่าช้ากว่ากำหนดมาถึงแล้ว เลยเวลานัด ท่ายังไม่ว่างคนขับรอในลานจอด
ถึงคิวของคุณแล้วระบบหรือเจ้าหน้าที่เรียกเข้าท่าคนขับ และลูกค้านำรถเข้าท่าตามที่ระบุทันที
เลยเวลานัดแล้วเลยเวลานัด ยังไม่เช็คอินคนขับ และลูกค้ารีบมาถึง หรือติดต่อคลัง
ยกเลิกคิวลูกค้ายกเลิกเอง คลังยกเลิก หรือไม่ชำระเงินตามกำหนดลูกค้า / ผู้ขายจองใหม่จากลิงก์เดิมได้
ปิดคิว: ไม่มาตามนัดไม่มาภายในเวลาที่กำหนดลูกค้า / ผู้ขายจองใหม่ หรือติดต่อเจ้าหน้าที่
หมายเหตุ · คนขับได้รับข้อความเฉพาะเมื่อเปิดลิงก์สำหรับคนขับผ่าน LINE แล้ว และเป็นเพื่อนกับ LINE OA

เมนู LINE

คิวของฉัน · สถานะ SO · ติดต่อคลัง

กดเมนูด้านล่างห้องแชทเพื่อดูข้อมูลล่าสุดได้ตลอดเวลา

  1. คิวของฉัน — คิวที่ยังไม่เสร็จตั้งแต่วันนี้เป็นต้นไป พร้อมสถานะ ท่า และเลข DO เลื่อนซ้าย–ขวาเพื่อดูคิวถัดไป
  2. สถานะ SO — เอกสารที่เปิดอยู่ สถานะการชำระเงิน และคิวของเอกสาร กด จองคิว เพื่อจองจากเมนูได้ทันที
  3. ติดต่อคลัง — เบอร์โทรและที่อยู่ของคลังแต่ละสาขา
หมายเหตุ · พิมพ์คำว่า คิว SO หรือ ติดต่อ ในห้องแชทได้ผลเหมือนกดเมนู · แสดงสูงสุด 10 รายการต่อครั้ง

คนขับ

สำหรับคนขับ

คนขับไม่ต้องสมัครหรือล็อกอิน ใช้ลิงก์สำหรับคนขับที่ได้รับจากลูกค้าหรือเจ้าหน้าที่

ซ้าย: ใบงาน · กลาง: ท่ายังไม่ว่าง กรุณารอ · ขวา: ถึงคิว เชิญเข้าท่า

  1. ลูกค้ากด ลิงก์สำหรับคนขับ ในการ์ดยืนยันคิว แล้วส่งต่อให้คนขับทาง LINE
  2. คนขับเพิ่มเพื่อน LINE OA (@307ghkbr) แล้วเปิดลิงก์ผ่าน LINE 1 ครั้ง
  3. วันนัด เมื่อถึงคลัง กด ฉันมาถึงแล้ว — เช็คอิน ในหน้าคนขับ (ต้องเปิดตำแหน่ง GPS) หรือแจ้งเลขคิวที่ป้อมยาม
  4. รอในลานจอด เมื่อถึงคิว LINE แจ้ง ถึงคิวของคุณแล้ว พร้อมชื่อท่า
หมายเหตุ · คนขับที่ไม่ใช้ LINE เปิดลิงก์ในเบราว์เซอร์แล้วกด เปิดแจ้งเตือน แทนได้ (iPhone ต้องเพิ่มหน้าเว็บไปยังหน้าจอโฮมก่อน)

อาการวิธีแก้
กดเมนูแล้วขึ้น "ยังไม่พบข้อมูลของคุณ"เปิดลิงก์จองคิว (หรือลิงก์คนขับ) ผ่าน LINE 1 ครั้ง แล้วกดเมนูอีกครั้ง
จองแล้วไม่ได้รับข้อความตรวจว่าเพิ่มเพื่อน OA แล้วและไม่ได้บล็อก · เปิดลิงก์ผ่าน LINE ไม่ใช่เบราว์เซอร์
หน้าจองขึ้น "เชื่อมต่อ LINE ไม่สำเร็จ"ยังจองได้ตามปกติ ปิดแล้วเปิดลิงก์ใน LINE ใหม่ หากยังไม่ได้แจ้งเจ้าหน้าที่
ลิงก์หมดอายุ / ไม่พบหน้าขอลิงก์ใหม่จากฝ่ายขาย / ฝ่ายจัดซื้อ
ต้องการเปลี่ยนทะเบียนรถหรือคนขับเปิดลิงก์จองเดิม กด เปลี่ยนทะเบียนรถ / คนขับ (ก่อนเช็คอิน)
พิมพ์ถามในแชทแล้วไม่มีคนตอบLINE OA ตอบอัตโนมัติเท่านั้น ติดต่อเจ้าหน้าที่โดยตรง

การทดสอบ

ขั้นตอนทดสอบกับ LINE OA จริง

สำหรับทีมทดสอบ — ใช้โทรศัพท์ 2 เครื่อง (ลูกค้า และคนขับ) ทำตามลำดับ

#ทำผลที่ควรเห็น
1ลูกค้าเพิ่มเพื่อน OAข้อความต้อนรับ + เมนู 3 ปุ่ม
2ฝ่ายขายเพิ่ม SO ทดสอบ แล้วส่งลิงก์จองให้ลูกค้าทาง LINEการ์ด "จองคิวรับสินค้า"
3ลูกค้าเปิดลิงก์ผ่าน LINE แล้วจองคิวแถบ ✅ รับแจ้งเตือนทาง LINE แล้ว · การ์ด "รับคำขอจองคิวแล้ว"
4ฝ่ายขายบันทึกชำระเงิน คลังอนุมัติคิวการ์ด "ยืนยันคิวแล้ว" พร้อมเลข DO
5ลูกค้ากดเมนู คิวของฉัน / สถานะ SO / ติดต่อคลังแสดงคิวและเอกสารของตนเองเท่านั้น
6ลูกค้าส่งลิงก์คนขับ คนขับเพิ่มเพื่อน OA แล้วเปิดผ่าน LINEหน้าคนขับแสดง ✅ รับแจ้งเตือนทาง LINE แล้ว
7คลังเลื่อนคิว 1 ครั้งลูกค้าได้การ์ด "เจ้าหน้าที่เลื่อนคิวของคุณ"
8คนขับเช็คอิน คลังเรียกเข้าท่าคนขับและลูกค้าได้การ์ด "ถึงคิวของคุณแล้ว"
9จองคิวที่ 2 แล้วลูกค้ายกเลิกเองการ์ด "ยกเลิกคิวแล้ว"
หมายเหตุ · บันทึกผลแต่ละข้อ (ผ่าน / ไม่ผ่าน + ภาพหน้าจอ) แล้วส่งให้ทีมพัฒนา
